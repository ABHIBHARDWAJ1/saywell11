CHROME EXTENSION

Saywell, wherever you type.

Select text or type in the popup. Saywell shows what it notices, offers a clearer version, and lets you copy it or replace your text, all without leaving the page. It never reads a page on its own.

Download saywell-extension.zipFree. Works in Chrome, Edge and Brave.

Install in one minute

  1. Download the zip above and unzip it. You get a folder called extension.
  2. Open chrome://extensions and switch on Developer mode (top right).
  3. Press Load unpacked and choose the unzipped folder.
  4. Pin Saywell from the puzzle icon. Select text on any page and press Alt+Shift+S, or right-click and choose SAYWELL → Analyze selection or Rewrite selection.

Private by design

Only when you ask

Nothing is analyzed until you press the shortcut, the menu item or the popup button.

Text goes to Saywell only

The selected text is sent to the Saywell server for analysis. No page is scanned in the background.

You stay in control

“Replace text” always asks first, and only replaces if the text box has not changed. Automatic checking while you type is off unless you turn it on.

Open the full app

“Open in SAYWELL” carries your text into Analyze so you can choose a version.
